# 繁體中文（台灣）書寫規範

本 skill 產出的所有中文 —— 回覆、文件、註解、commit 訊息 —— 一律是**繁體中文、台灣用語、台灣標點慣例**。

---

## 1. 三條底線

1. **簡體字直接是紅旗**，出現一個就整份重看一次。
2. **大陸用語一律改台灣用語**。高頻詞驗證器會直接抓（清單在 `assets/voice-profile.json`）；語境相依的詞看第 4 節。抓到一個詞，就把該詞在整份文字掃完，不要只改被看到的那一行。
3. **中文與英數之間空一個半形空格**。

```text
✔ 這一篇會用到 Web Crypto API，需要 Node.js 18 以上版本。
✘ 這一篇會用到Web Crypto API，需要Node.js 18以上版本。
```

中文與**全形標點**之間**不空格**：寫「，Docker 就會…」不是「， Docker 就會…」。

---

## 2. 標點

### 2.1 全形為主

句號、逗號、頓號、問號、驚嘆號、冒號、引號在中文語境一律**全形**：`，。、？！：「」`

半形只出現在三個地方：程式碼、路徑與版本號、純英文句子內部。

### 2.2 引號

- **「」**：框引用的話、錯誤訊息原文、UI 按鈕與選單文字、術語首次出現。
- **不要拿「」框一般描述性文字** —— 這是最容易被讀出 AI 味的地方。
- **『』**：只用在引號中的引號。用量極低，沒把握就不要用。

### 2.3 其他符號

| 符號 | 規則 |
| ------ | ------ |
| 括號 | 中文語境用全形 `（）`；英文縮寫緊貼原文時用半形不空格，如 `CRA(Create React App)` |
| 刪節號 | 寫半形三點 `...`，不寫 `…` 或 `……` |
| 波浪號 | 全形 `～` |
| 分號 | 中文句中幾乎不用，改用逗號或直接斷句 |
| 刪除線 | `~~文字~~` 放一句真心話吐槽，一次就好 |
| 表格分隔線 | 要有空格：`| ------ |`，不寫 `|------|` |

## 3. 台灣語感詞

「沒有用大陸用語」不等於「像台灣人寫的」。這幾組是硬偏好：

<!-- check-voice-disable -->

| 用這個 | 不用這個 |
| ------ | ------ |
| 滿（滿多的、滿重要的） | 蠻 |
| 這邊 | 這裡 |
| 簡單來講 | 簡單來說 |
| 舉例來講 | 舉例來說 |
| 唷 | 喔 |
| 可是 | 但是 |
| 等等（句尾列舉） | 等 |
| 我 | 筆者、本人 |

<!-- check-voice-enable -->

台灣日常詞不要換成書面詞：程式碼、套件、資料夾、影片、解析度、隨身碟、滑鼠、函式庫、當機、噴錯。

**描述用語差異時對詞不對人。** 詞彙對照是中文寫作風格選擇，不是在指人；不要用貶義的人群或腔調標籤 — 這類字眼連當反例引用都不要寫出來。要講用語問題就講「這個詞台灣不這樣講」。

## 4. 語境陷阱（不能無腦替換）

<!-- check-voice-disable -->

- **文件**：大陸的「文件」＝台灣的「檔案」（file）；台灣的「文件」＝ document。看語境判斷。
- **程序**：大陸的「程序」＝台灣的「程式」（program）；台灣的「程序」＝流程／procedure。
- **對象**：指 OOP object 用「物件」；指人際交往對象是正常中文，不改。
- **代碼**：指 source code 要改成「程式碼」；股票代碼、國家代碼、錯誤代碼是正常台灣用語。
- **質量**：指 quality 改「品質」；物理學的 mass 不改。
- **支持**：支持一個人或想法是正常台灣用語；technical support 才用「支援」。
- **實現**：實現夢想是正常台灣用語；implement 用「實作」。
- **循環**：循環經濟是正常台灣用語；loop 用「迴圈」。
- **數據**：數據分析、量化數據在台灣是通用說法；DB 意義的 data 用「資料」。
- **配置、布局、渲染、映射、協程、日誌**：兩岸皆有人用，台灣側也接受 — 專案既有慣用優先，不強改。

**管理黑話一律不用**：賦能、抓手、顆粒度、閉環、鏈路、對齊、複盤、乾貨、深度好文、痛點解決方案。

## 5. 怎麼檢查

```bash
node scripts/check-voice.mjs -m "文字"        # 一段回覆
node scripts/check-voice.mjs draft.md         # 一份 markdown
```

檢查器抓得到簡體字、高頻紅旗詞、中英空格、半形標點、慣用寫法。第 4 節那類語境相依的詞它只給 warning，最後還是要人看。
